# 汉鸿店铺 · 数据战情室 Pro

> 阿里巴巴 1688 店铺实时数据看板，支持 GitHub Pages 部署，只需更新 `data.xlsx` 即可刷新数据。

---

## 🚀 快速开始（GitHub Pages）

### 第一步：Fork 本仓库
点击右上角 **Fork**，克隆到你自己的账号。

### 第二步：开启 GitHub Pages
仓库 → Settings → Pages → Source 选择 `main` 分支 / `/ (root)` 目录 → Save。

稍等 1~2 分钟后访问：`https://<你的用户名>.github.io/<仓库名>/`

### 第三步：上传 / 更新数据
将 **`data.xlsx`** 上传到仓库根目录，刷新页面即可。

## 📊 data.xlsx 表头格式

| 列名（任选其一均可识别）| 说明 |
|---|---|
| 日期 / date | 格式：2025-01-01 或 Excel 日期格式 |
| 总展现 / 展现量 / 曝光量 | 当日展现总数 |
| 广告展现 / 广告曝光 | 广告展现数 |
| 自然展现 / 自然曝光 | 自然展现数 |
| 访客 / 访客数 | 当日访客数 |
| 询盘 / 询盘数 / 商机 | 当日询盘数 |
| 接待 / 接待数 / 接待人数 | 接待对话数 |
| 广告花费 / 消耗 / 推广花费 | 当日广告消耗（元）|
| 线索 / 线索数 / 留资 | 留资线索数 |
| 成交金额 / 成交额 / 营业额 | 成交总金额（元）|
| 成交笔数 / 订单数（可选）| 成交订单数 |

> 表头顺序不限，系统自动识别；不需要的列可不填。

## 🔄 日常数据更新流程

```
1. Excel 填写新的每日数据行 → 另存为 data.xlsx
2. 上传到 GitHub 仓库根目录（覆盖原文件）
3. 等待约 30 秒 GitHub Pages 缓存刷新
4. 访问看板 → 点击「🔄 刷新数据」
```
